# FCC adapter and source-credits verification

Run `npm run check` and `npm run build -w apps/web`. Set `MOT_EVIDENCE_DIR` to a writable directory, then run `node scripts/verify-mot-fcc-live.mjs` with the supported Node runtime. This is a read-only public-source check: it reads FCC's city-feed index and each listed feed through the actual MoT adapter, eight requests at a time. It compares complete article bodies, titles, canonical URLs, dates, source versions, city provenance and independently computed SHA-256 hashes; venue identities/counts are checked too. Requests omit credentials and carry no board/model data. Four cities reopen from cache without another fetch. The receipt records exact counts and time; this is not a parity check against every native FCC webpage or an offline cold start.

The city adapter applies its existing `timeoutMs` setting with a 20-second maximum, matching the established public-content ceiling. That deadline covers both response headers and body parsing across all attempts. Explicit cancellation and timeout settle even if injected transport ignores AbortSignal. Timeout returns the existing retryable network error and preserves a dated previous issue as stale; explicit cancellation stays cancelled. No late response can replace the cache. A diagnostic callback failure cannot replace the typed result. The cache interface, schemas, retry cap, allowed origins and Almanac behavior are unchanged. Cache-storage latency is separate from the network deadline.

`packages/core/src/trip/fcc-city-settlement.test.ts` covers an uncooperative fetch, stalled JSON body, late cache write, explicit cancellation and a failing diagnostic sink. Fake timers exercise the actual 20-second ceiling without raising the test deadline. Existing FCC content/Almanac tests remain unchanged.

Start the app on 127.0.0.1:5198, set `MOT_PLAYWRIGHT_MODULE` to installed Playwright, and run `node scripts/test-mot-fcc-deadline.cjs`. It uses the public San Sebastián feed saved by the live script, seeds a dated public-content cache, then stalls the browser transport for the real deadline. The UI must recover with the saved issue/date, ignore the late response, preserve the trip and permit a manual card edit. It checks six widths and makes zero provider POSTs. `MOT_TEST_ORIGIN` overrides localhost. Browser plugin not available; use sandboxed Playwright Chromium. These viewport checks do not establish physical iOS/Safari behavior.

For R7-1, run `scripts/test-mot-magazine.cjs san-sebastian` using the licensed fixture setup in `MAGAZINE-QA.md`. Then run `node scripts/verify-mot-source-credits.cjs <city-evidence-directory>` with `MOT_PYTHON` pointing to a Python runtime containing pypdf and Poppler available as described there. The verifier reads the actual PDF's searchable text and URI annotations. Every source title must be complete and linked to the exact SVG target; source pages must show publisher/retrieval date and no raw metadata URLs, and notebook continuations must contain no unresolved FCC citation markers. It separately rasterizes source pages and applies the unchanged 4/255 preview/PDF gate. This verifies the existing source-credit implementation, without changing the layouts or claiming Opus sign-off. Existing unit coverage retains source cards, long-title pagination, unsafe-link rejection and private-source exclusion.
