## Human journey

Select a free-board card or unlocked image, open Arrange selected item, then Copy to another trip. Preparation freezes permitted metadata before reading original bytes. The panel explains that system copying includes selected notes, full originals/source images, cropped-out content and embedded metadata, accessible to other apps. Copy to system clipboard starts its native write only from that informed click. Keep in this app stores one bounded frozen copy in this tab; a later explicit copy replaces it. Clear in-app copy removes it. A failed native write reports the working in-app fallback, never system-copy success.

Switch trips normally. Paste is available on an empty board. Read system clipboard, native paste on the canvas, or Use in-app copy opens the same private-copy preview with label and actual item/image counts including ancestors. Add private copy performs the insertion; Cancel writes nothing. Copy/paste panels receive keyboard focus and return it to the trigger on closure. Ordinary same-board Copy/Ctrl+C and text-field shortcuts retain their previous behavior. Regular text, URLs and image files retain their existing paths; a recognizable invalid board envelope refuses visibly instead of becoming a large note.

Completed in-app copies survive trip navigation, not tab closure/reload. System transfer uses a versioned text/plain envelope and never treats a serialized source board ID as authority or as a request to open that board. Original bytes are not sanitized for this explicitly disclosed private copy. No URL in pasted metadata is fetched. Source attribution is imported data.

## Atomic graph and media lifecycle

`trip_board_paste` independently rejects agents, validates target identity/revision and the strict complete graph, allocates every new ID internally, reserves IDs across all destination maps/source IDs/intra-batch allocations, remaps every media/derivedFrom reference and validates all candidate records before its first Yjs write. It makes one command/Undo step. Yjs transaction exceptions do not roll back partial writes, so full synchronous preflight is required; executeAll trial IDs are not substituted for it.

All copied card/presentation scopes are private. CreatedBy comes from the current human and provenance becomes traveler. Booking, bookingAttention, lineage, original actor/sharing authority and confirmed currentFacts are absent from the wire projection. Complete observations are appended to original sourceText as labelled unverified JSON with dates and URLs; overflow rejects without truncation. Saved day/time/stage, source, notes, crop, relative geometry, credit and rights remain. Imported apparel metadata, locked/magazine/card-linked images and unrelated graph records refuse rather than acquiring magazine authority. Board rotation remains zero. Relative positions translate to the captured viewport origin; source stack values remain subject to existing bounds, with no clamping or unrelated layout changes.

The browser verifies actual SHA-256, all bounded headers and native oriented dimensions through the unchanged R23 shared serial decoder. Staged originals enter the existing commitTripBlobs RAM lifecycle, then the one synchronous graph command runs with an immediate signal/context/revision check. Precommit failure restores staged RAM and leaves document/history/storage unchanged. Duplicate callbacks apply once. Notification exceptions cannot invalidate committed originals. Postcommit storage failure retains recoverable originals in this tab and reports that state; it does not promise document/blob-store atomicity.

Pending work is fenced to the initiating session/actor/view/revision/operation token. Cancel, leave/return and deliberate retry cannot revive an old gesture. A ready frozen source snapshot is independent of later source edits. Native clipboard writes already initiated by an informed click are browser operations that cannot be revoked; obsolete completion feedback is fenced.

Personal native ZIP collection/filtering now walks only selected asset ancestors, verifies collected original bytes and retains their metadata/bytes through actual package export/import. Shared export selection is not widened. Missing/cyclic ancestry refuses. Existing 10 MiB per-file/50 MiB whole-package limits remain: an entire populated trip may not fit even when one clipboard gesture fits. Tab-only ZIP recovery is available only when the package itself fits those limits.

The existing agent media guard now protects the complete private-root ancestry and the requested source ancestry. Fresh attach/register candidates also check derivedFrom; proposal prevalidation checks the same references. No-media operations return before media traversal. Human operations remain under existing rules.
