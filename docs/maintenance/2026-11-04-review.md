# Code review and cleanup — 4 November 2026

Scope: tracked code, dependencies and documentation. Remote branches, history and release acceptance requirements are outside this cleanup. The source baseline was `beacda35b01a84356d0373e5546736bec300624e`, including the previously requested logo update.

## Findings and changes

- **Shared export cancellation:** a caller joining an existing city-art lookup could not cancel promptly, and an already-cancelled caller could receive a cached result or start a lookup. Five new regression tests cover these cases, successful cache sharing, listener cleanup and retry after the original caller cancels. The original implementation failed four of those tests. Each caller now stops waiting independently; the existing lookup ownership and retry behavior remain intact.
- **Duplicate bitmap handling:** artwork and trip-media exports repeated the same cancellation and bitmap cleanup logic. Both now use `exportBitmapDimensions`. Existing cancellation and apparel tests exercise the callers, including cleanup when a bitmap completes after cancellation.
- **Unused dependencies:** removed eight unused font packages, Three.js, its React integrations and its type package. Removed the orphan font declaration and unused production imports. The lockfile loses 60 package entries without changing retained package versions.
- **Undeclared web dependency:** the first clean install after removal exposed 15 failing test files because the web workspace imported `fflate` without declaring it. A previous transitive dependency had masked that error. Declaring `fflate` directly in the web workspace fixes clean installs; a second clean install and the full checks passed.
- **Documentation:** added a current development guide, documentation index and scripts index. Moved the October demo reports under `docs/history/2026-10-demo/`, preserved their historical results and corrected their relative links. Current release and acceptance guidance stays in place.
