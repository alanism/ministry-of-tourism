API specification · Capabilities · Cities · Plain-text instructions

The conversation/helper route has been reported working for Bangkok and Copenhagen. The tested Mac Settings screen offers no Add/Custom/OpenAPI control for an unlisted connector; a Settings entry is not required for this route. This is a public HTTP API, not a native MCP server or a Meta-approved directory listing. Records come from a saved public snapshot; current opening hours, availability and prices are not verified. Credits and usage restrictions travel with each record.

The API can read public catalogue records only. It cannot open your saved trips, change boards, book or buy anything. Trip changes continue through the existing browser/file review workflow.
